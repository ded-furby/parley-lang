What shipped

General product capability

Strict typed JSON

Request and response types are inferred from handler signatures. Unknown fields, malformed bodies, wrong media types, unsafe maps, and invalid handler shapes fail explicitly.

Bounded native HTTP

Header/body limits, timeouts, conflicting-length rejection, no chunked ambiguity, canonicalized static paths, correct content lengths, and nosniff responses.

Deterministic browser ABI

Scalar exports compile to wasm32-unknown-unknown. The checker walks their call graph and rejects terminal I/O, files, randomness, closures, and dynamic calls.

Release Radar dogfood

The browser previews readiness through WASM; the native API independently returns the typed assessment. The verified ready flow produced 100 in both places.

Honest boundary

This is not framework parity yet. The server is HTTP/1.1 with one thread per connection, no TLS, WebSockets, dynamic path parameters, middleware, databases, or auth. Browser exports are scalar-only. The next evidence step is a frozen, independent Release Radar comparison against Python, TypeScript, and Rust—not syntax tuning.
