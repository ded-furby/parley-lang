v0.4.1 — measured, then cut

Attribution before design

Every unique paired Parley/Python/Rust program in the frozen corpora was tokenized with o200k_base and the excess over Python attributed phrase by phrase. Parley source was 37.8% larger than Python — the opposite of the pitch. Two shapes accounted for most of the recoverable difference.

Top-level statementsStatements at the top level are the body of main. Removes a wrapper line and one indent level from every program: 531 tokens (5.0%).

v0.4.3 — it could not read its own arguments

Found by writing tasks a user would assign

The entire outside-world surface was ask, read file, write to file, and a random number. A program could not take a command-line argument, could not loop over stdin without treating end-of-input as a failure, and could not look at a directory. Parley could be a filter with hardcoded paths; it could not be a tool.

the arguments · the inputBoth plain list of text. the input names a value, not a stream: stdin drains once and every later mention sees the same lines.

v0.4.4 — JSON, typed

The last category-blocking gap

The compiler already inferred JSON contracts for web routes, but a plain program could not read a config file. JSON now enters as a record you declared — there is no dynamic any value to pick apart later, so a decoded document is as statically typed as the rest of the program and a schema mistake is a check-time error.

v0.5.0 — generic functions

The oldest structural hole

std/list holds 279 functions for 94 operations, because every one needs a number, text, decimal, and yesno copy — and a user could not write a reusable helper across types at all. A type may now be written any name.

Honest boundary

The token result is a source measurement, not a session measurement. Report 030 put the Parley/Python gap at roughly 2,010 fixed tokens per session plus 74 residual tokens per task, so a 6.6% source cut is not a 6.6% session cut and no fresh-agent claim follows from it. Nothing here was measured by re-running a frozen benchmark, and no preregistered protocol was touched. Parley is now a language I would choose for local file, text, and data work; it still has no HTTP client, no regex, no process spawning, and no concurrency. The 279-function stdlib is still 279 functions: generics make that cleanup possible, they do not perform it.
