# Fresh-agent full-stack study 041

Iteration 041 is an independent successor to the invalidated study 040. Its
first checkpoint contained task and case semantics only. Parley v0.5.2 and the
generic scratch-capacity control were committed before these names, formulas,
routes, fixtures, or defect mechanisms were selected. Later commits preserved
that checkpoint while freezing, executing, and publishing the full study.

## Frozen task population

The corpus has four assignments:

1. Build an observatory schedule with public/research sessions, cloud-watch
   time, floor-divided breaks, staff load, and operating modes.
2. Build a reef nursery flow planner with day/night requirements, pump
   capacity, served/overflow flow, and nursery states.
3. Repair a mountain shelter that allocates warming capacity before applying
   the storm-lockdown reduction.
4. Repair an aviary that omits rehabilitation birds from the winter ration.

Each assignment has a unique typed POST route, a unique status route, a
deterministic scalar ES-module export, four public cases, and five hidden
cases. Both visibility sets include real-browser judgment. The field named by
`shared_result_field` must agree with the browser result for equivalent input.

## Independence boundary

Task IDs, case IDs, request fields, response fields, status routes, POST routes,
and browser exports are disjoint from iterations 036–040. The observatory,
reef, shelter, and aviary domains, formulas, fixtures, adjustment-before-
allocation defect, and conditional subset-omission defect were new at the
corpus checkpoint. No scaffold, reference implementation, agent prompt, model
output, threshold, or protocol existed when those semantics were committed.

The population deliberately mixes floor division, multiplication, guarded
subtraction, minimum/maximum clamps, boolean adjustments, capacity allocation,
and three-way states. The two maintenance defects target different mechanisms
from 040's protected-reserve ordering and lift-polarity defects.

Task and case files were committed alone before any stack implementation or
comparison protocol. The later protocol binds that commit and its exact file
hashes. Execution code made the contracts runnable without changing their
semantics or expected values.

## Scratch-control boundary

The protocol binds `benchmarks/scratch_space.py`, its worker budget, and
disjoint work/journal/attempt roots. Preflight must pass before journal
initialization. Every cell workspace may be reclaimed only after its finished
journal and external attempts are durable. This infrastructure control cannot
exclude, retry, or reinterpret a started cell.

## Claim boundary

Any positive condition supports only the frozen models, stacks, tasks, and
session protocol preregistered for 041. Four synthetic assignments cannot prove
universal superiority, production-framework parity, or performance in
unmeasured domains. Every cell and failure is published without selective
reruns or correctness-conditioned efficiency filtering.
