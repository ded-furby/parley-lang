# Full-stack agent study 047 preregistration

Study 047 is a frozen 32-session pilot of unseen exact and parameterized route
work in Parley 0.5.7, Python, TypeScript, and Rust. It uses four tasks, one
`gpt-5.6-sol` medium-reasoning configuration, and two replicates per
task/language cell.

The product, 176-token Parley context, and corpus were committed in that order
before this protocol. The corpus contains two implementations and two
predeclared route-handler repairs. Every task receives five public and five
hidden cases spanning HTTP routing, decoded/safe captures, exact response
headers, and real-browser score execution.

The primary gate requires complete execution integrity, 100% Parley hidden
correctness with no lower assignment success than any baseline, no lower
first-check success, no higher median complete tokens or elapsed time than the
best baseline, and no worse exact-root maintenance. All conditions are
reported independently.

No measured session may start under revision 1. Revision 2 must bind and
validate the complete harness, all 16 reference applications, 160 named case
executions, eight maintenance negative-control roots, scratch capacity, and
live-to-persisted routing evidence with zero measured sessions.

Two replicates make this a pilot rather than population-level confirmation.
Even a fully passing result would support only this frozen comparative claim,
not universal language superiority.
