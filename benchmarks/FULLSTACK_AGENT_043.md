# Fresh-agent full-stack study 043

Iteration 043 is the independent validation target for Parley v0.5.4's cold
typed-web build improvement. The product and unchanged 222-token agent context
were committed and hash-frozen before these tasks, routes, fields, formulas,
fixtures, or defect mechanisms were selected.

## Frozen task population

The semantics-only corpus has four assignments:

1. Build a wildfire drone mission planner with scout/cargo flight loads,
   conditional night setup, launch capacity, floor-divided waves, and mission
   modes.
2. Build a satellite uplink scheduler with science/navigation transmission,
   conditional solar interference, antenna capacity, floor-divided windows,
   and queue modes.
3. Repair an alpine gondola whose passenger and freight load coefficients are
   transposed.
4. Repair a kelp hatchery that selects the greater of oxygen need and aeration
   capacity as delivered oxygen instead of the lesser.

Each assignment has one exact status route, one typed POST route, one
deterministic scalar browser export, four public cases, and five hidden cases.
The 36 cases include real-browser coverage and require equivalent HTTP/browser
inputs to agree on the declared shared result.

## Independence boundary

Automated checks prove that all task IDs, case IDs, request fields, response
fields, status routes, POST routes, and browser exports are disjoint from
iterations 036–042. The coefficient-transposition and extremum-selector defects
are new and publicly observable. No 043 scaffold, reference implementation,
protocol, model configuration, threshold, runner change, or agent output
exists at this checkpoint.

## Claim boundary

A positive result could support only the later preregistered stacks, models,
tasks, and execution protocol. Four synthetic contracts cannot establish
universal superiority, production readiness, ecosystem breadth, or unmeasured
performance. Every started cell and failure must remain published without
selective reruns or correctness-conditioned efficiency filtering.

Next: commit this semantics-only boundary, then preregister the balanced matrix,
six-condition gate, v0.5.4 product, context, scratch budget, evidence order, and
no-rerun behavior before implementing any 043 scaffold.

## Measured result

All 96 once-run cells completed with unique threads, immutable journals,
attempt evidence, and verified cleanup. All 96 assignments passed their first
public check and hidden judgment, covering 384/384 public named cases, 96
public Chromium cases, 480/480 hidden named cases, 192 hidden Chromium cases,
and all cross-target agreement checks. All 288 exact-build boundaries remained
stable and all 12 maintenance cells per language changed their exact declared
root.

Parley had the lowest overall median complete-session token count at 60,206.5,
0.8253% below Python's 60,707.5, and remained lower under both model
configurations. Parley was also fastest overall at 26.2831 seconds versus
Python's 26.7349 seconds. The elapsed condition nevertheless failed because
terra-medium Parley took 26.2647 seconds versus Python's 25.5915 seconds, a
2.6306% gap. The strict all-six result is therefore false: execution integrity,
correctness, first check, tokens, and maintainability passed; elapsed failed.

The complete paired attribution retains all 24 Parley/Python pairs. Parley was
slower during the public build in 24/24 pairs by 2.935 seconds at the paired
median; under Terra the build delta was 3.34245 seconds. Excluding that measured
component is diagnostic only and does not alter the frozen result or authorize
tuning on this corpus.
