# Fresh-agent full-stack study 038

Iteration 038 is an independent successor to invalid study 037. Its first
checkpoint contains only task and case semantics. The exact-build freeze
mechanism was committed before any of these names, formulas, routes, fixtures,
or defect mechanisms existed.

## Frozen task population

The corpus has four assignments:

1. Build a ferry manifest charge service with passenger, vehicle, and peak
   components.
2. Build an archive retention index with a legal-hold floor and review batches.
3. Repair loyalty rewards that are incorrectly derived before claimed stamps
   are subtracted.
4. Repair a cold-storage evaluator that ignores the door-open temperature
   correction.

Each assignment has a status route, typed JSON route, deterministic scalar ES
module export, four public cases, and five hidden cases. Public and hidden sets
both include real-browser judgments. The response field named by
`shared_result_field` must agree with the browser result for equivalent input.

## Independence boundary

The 038 IDs, request fields, response fields, POST routes, browser exports, and
case IDs are disjoint from both 036 and 037. Product domains, formulas,
fixtures, and the two repair mechanisms are new. No earlier transcript or
solution informed the semantics.

The only intentional inheritance is execution plumbing: the parent-owned FIFO
checker from 037 and the exact-build post-command hash validator proven at
commit `6e50439`. Neither mechanism smoke contained any 038 task content.

Task and case files are committed as their own freeze checkpoint before any
038 scaffold, reference implementation, comparison protocol, threshold, or
measured session. A later protocol must record this commit and both exact file
hashes. Execution implementation may make the contracts runnable but may not
change their semantics or expected values.

## Claim boundary

A positive result can support only the frozen models, stacks, tasks, and
session protocol. Four synthetic assignments cannot prove universal language
superiority, production-framework parity, or quality in unmeasured domains.
Every cell and failure must be published without selective reruns or
correctness-conditioned efficiency filtering.
