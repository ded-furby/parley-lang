# Fresh-agent full-stack study 037

Iteration 037 is the independent successor to invalid study 036. It keeps the
same broad question—fresh-agent reliability and complete-session cost across
Parley, Python, TypeScript, and Rust—but replaces every assignment semantic
and uses the parent-owned public checker proven before this corpus was created.

## Frozen task population

The corpus has four assignments:

1. Build a rail connection evaluator with transfer-buffer and missed-train
   boundary behavior.
2. Build an orchard irrigation scheduler with rainfall credit and ceiling
   pump-cycle calculation.
3. Repair a tiered usage calculation that prices included units at the excess
   rate.
4. Repair a timeline bucketer that assigns exact-boundary events to the next
   bucket.

Each assignment has a status route, typed JSON route, deterministic scalar ES
module export, four public cases, and five withheld cases. Public and hidden
sets both exercise HTTP and real Chromium behavior. The response field named
by `shared_result_field` must equal the browser result for equivalent inputs.

The two maintenance defects are synthetic boundary mechanisms selected before
any scaffold or model output. They predeclare the application-logic module as
the sole root-cause role. No upstream source or test is copied.

## Independence boundary

The transport smokes were completed before these tasks existed and contained
only a constant `42` fixture. The 037 corpus does not reuse any 036 task name,
request field, response field, route, browser export, product domain, formula,
case ID, or fixture. No 036 transcript or solution informed the semantics.

The task and case files are committed as their own freeze checkpoint before
any 037 language scaffold, reference implementation, protocol threshold, or
measured session. A later protocol must record their exact commit and SHA-256
hashes. From that point onward, execution work may make the frozen contracts
runnable but may not alter their semantics or expected values.

## Public-check boundary

Agent sessions retain `sandbox_workspace_write.network_access=false`. Their
protected `./check` command sends an authenticated request over POSIX FIFOs to
the parent runner. Only the parent binds loopback, runs public HTTP cases, and
drives real Chromium. It returns bounded public feedback and stores the full
attempt outside the workspace. Hidden cases remain separate and never enter
the public channel. See `AGENT_CHECK_TRANSPORT.md`.

## Claim boundary

A positive result can support only a claim about the frozen models, stacks,
tasks, and session protocol. Four synthetic assignments cannot prove that any
language is universally best, establish production-framework parity, or
justify claims about unmeasured domains. Every cell and failure will be
published without selective reruns or exclusions.

Task and case semantics are frozen, and the balanced 96-cell protocol is
preregistered in `fullstack_agent_037_protocol.json`. The four stack generators,
parent evaluator, shared numeric-domain guard, exact Rust lock, provenance
preparer, journaled runner, and integrity aggregation are implemented. The

without incorrectly passing. No measured 037 session exists at this checkpoint;
the exact transitive harness hashes and zero-session controls are frozen in
