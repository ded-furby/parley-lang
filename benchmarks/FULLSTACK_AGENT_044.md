# Fresh-agent full-stack study 044

Iteration 044 is the independent validation target for Parley v0.5.5's
dependency-free typed-route JSON build path. The product, accepted build
evidence, and unchanged 222-token agent context were committed and hash-frozen
before these tasks, routes, fields, formulas, fixtures, or defect mechanisms
were selected.

## Frozen task population

The semantics-only corpus has four assignments:

1. Build a seismic sensor array with short/deep scan loads, conditional ash
   synchronization, relay capacity, floor-divided rounds, and array states.
2. Build a museum conservation scheduler with canvas/textile workloads,
   conditional emergency drying, table capacity, floor-divided rounds, and
   conservation states.
3. Repair a canal lock whose flood-protocol condition is reversed.
4. Repair a thermal greenhouse whose heating-cycle divisor is 23 instead of
   29.

Each assignment has one exact status route, one typed POST route, one
deterministic scalar browser export, four public cases, and five hidden cases.
The 36 cases include real-browser coverage and require equivalent HTTP/browser
inputs to agree on the declared shared result.

## Claim boundary

A positive result could support only the later preregistered stacks, models,
tasks, and execution protocol. Four synthetic contracts cannot establish
universal superiority, production readiness, ecosystem breadth, or unmeasured
performance. Every started cell and failure must remain published without
selective reruns or correctness-conditioned efficiency filtering.
