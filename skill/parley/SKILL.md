# Parley

Create `solution.par` first; use 4-space blocks and start `to main:`. Run only
`./check` and follow its diagnostics. Core forms: `let x be value`, `set x to
value`, `say value`, `ask ""`. `ask for a number ""` gives a maybe: check `is
nothing`, then use `value of`.
